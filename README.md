# Afnan Shahriar - Personal Portfolio

A modern, responsive portfolio website showcasing my academic background, professional experience, projects and technical skills.

## ✨ Features

- **Responsive Design** - Fully responsive layout that works on all devices
- **Dark/Light Mode** - Toggle between dark and light themes with persistent preference
- **Smooth Scrolling** - Smooth navigation to different sections
- **Binary & Matrix Backgrounds** - Decorative tech-themed animations
- **Project Cards** - Interactive cards showcasing projects
- **Downloadable CV** - Direct download link for resume

## 🛠️ Technologies Used

- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- JavaScript (ES6+)
- Font Awesome 6.4.0
- Google Fonts (Orbitron, Exo 2)

## 🚀 Getting Started

1. Clone this repository
2. Ensure all files are in the correct directory structure
3. Open `index.html` in your browser
